## 通用小提示

- 密钥只显示一次：创建后立刻复制，粘贴到“密钥与连接”对应卡片，点“保存并测试”。
- 复制时别带前后空格，页面会自动清理空格，但中间不能断开。
- 不要把密钥发给别人，也不要贴到群里。泄露后马上去服务商后台删掉旧密钥重新创建。
- 建议给大模型设置月度消费上限（OpenAI、Anthropic 后台都有），防止异常用量。
- 第一次用只充最少金额，跑通后再加。

## 1. 大模型（必填，选一家即可）

怎么选：想省事选 OpenAI 或 Anthropic；想省钱选 DeepSeek 或 Gemini 免费档；想先试用不花钱选 Gemini 免费档。填入“密钥与连接 → 大模型”卡片：服务商选对应名字，API 密钥粘贴到“API 密钥”框。

### 1.1 OpenAI

1. 打开 platform.openai.com，用邮箱或 Google 账号注册登录。[截图：登录页]
2. 注册时按提示验证手机号【待核实】。
3. 左侧进入 Billing（账单），点 “Add payment details” 填写银行卡。[截图：账单页]
4. 选择充值金额，最少 5 美元，默认 10 美元。关掉 “Auto-reload”（自动续费）可避免超预期扣款。
5. 左侧进入 API keys，点 “Create new secret key”，起名（例如 KeLai），复制密钥（以 sk- 开头）。[截图：创建密钥]
6. 粘贴到卡片的“API 密钥”框。

费用：按用量计费，预充值扣完即止，不会透支。免费额度：无。身份证件：不要。

### 1.2 Anthropic（Claude）

1. 打开 console.anthropic.com，用邮箱或 Google 账号登录。[截图：登录页]
2. 进入 Billing，购买额度，首次最少 5 美元（预付费）。
3. 进入 Settings → API Keys，点 Create Key，选默认工作区，起名后创建，立即复制密钥（只显示一次）。[截图：创建密钥]
4. 粘贴到卡片的“API 密钥”框。

费用：预付费，用完要续。免费额度：无。身份证件：不要。

### 1.3 Google Gemini（有免费档）

1. 打开 aistudio.google.com，用 Google 账号登录。
2. 点 “Get API key” → “Create API key”，选一个项目（没有就让它自动创建），复制密钥。[截图：Get API key]
3. 粘贴到卡片的“API 密钥”框。

费用：免费档不绑卡，有速率限制，适合试用；用量大时需要在 Google Cloud 里开通付费。注意：免费档下，你发送的内容可能被 Google 用于改进产品，业务敏感内容建议用付费档。身份证件：不要。

### 1.4 DeepSeek

1. 打开 platform.deepseek.com，注册并登录。
2. 左侧进入 API keys，创建并复制密钥。
3. 进入充值页充值（支持的付款方式以页面为准）。
4. 粘贴到卡片的“API 密钥”框。

费用（核对时的公开价，每百万 token）：deepseek-v4-flash 输入约 0.14 美元、输出约 0.28 美元；deepseek-v4-pro 标准价输入约 1.74 美元、输出约 3.48 美元。性价比最高的一档。身份证件：海外站不要。

### 1.5 通义千问（阿里云百炼）

1. 打开阿里云百炼控制台 bailian.console.aliyun.com，注册登录阿里云账号。[截图：控制台首页]
2. 在控制台找到 “API-KEY” 页面，创建并复制密钥。
3. 粘贴到卡片，服务商选“通义千问”。

免费额度：官方宣传新用户可领取大量免费 token（页面写“超 7000 万 Tokens”，以领取页为准）。身份证件：中国站账号通常需要实名认证，国际站【待核实】。

### 1.6 Kimi（月之暗面）

1. 打开 platform.moonshot.ai（国内站 platform.moonshot.cn），注册登录。
2. 进入 API Keys 管理页，创建并复制密钥。
3. 充值激活，最低约 1 美元【以充值页为准】。
4. 粘贴到卡片，服务商选“Kimi”。

价格（每百万 token，输入 / 输出）：K2.5 约 0.44 / 2.00 美元，K2.6 约 0.75 / 3.50 美元。无固定免费档。

### 1.7 智谱 GLM

1. 打开 bigmodel.cn，登录。
2. 点 “API 密钥”，添加新密钥并复制。
3. 粘贴到卡片，服务商选“智谱 GLM”。

免费额度：不定期有新人资源包，以平台活动为准。实名认证要求【待核实】。

### 1.8 MiniMax

1. 打开 platform.minimax.io（国内站 platform.minimaxi.com），点 Console，用邮箱注册。
2. 左侧点 Access → Create new API key，起名后确认并复制。
3. 在控制台充值（用量计费，需要付款方式）。
4. 粘贴到卡片，服务商选“MiniMax”。

价格：M3 约 0.30 美元 / 百万输入 token、1.20 美元 / 百万输出 token。新账号有试用额度，验证手机号或邮箱后发放，额度以控制台为准。

## 2. Telegram 接口凭据（必填）

对应卡片：密钥与连接 → Telegram 接口凭据，字段 api_id 填数字，api_hash 填 32 位字母数字。

1. 打开 my.telegram.org，输入你的 Telegram 手机号（含国际区号，例如 +66…）。[截图：登录页]
2. Telegram 里会收到一条验证码消息，回到网页输入。
3. 点 “API development tools”。[截图：入口]
4. 第一次会让你创建应用：App title 和 Short name 随便填（例如 KeLai、kelai），Platform 选 Other，其余可空，点 Create application。
5. 页面显示 api_id（纯数字）和 api_hash（32 位字符），分别粘贴到卡片两个框。[截图：结果页]
6. 回到“Telegram 账号”页，用同一手机号登录。

注意：
- 不要证件，不要银行卡，免费。
- 页面报 ERROR 时，常见原因是网络或浏览器问题：换浏览器或无痕窗口、稍后再试，必要时换网络；不要连续反复点，会触发限制。
- api_id / api_hash 属于这个手机号对应的账号，不要分享。
- 建议用专门的业务号而不是私人号，号上开启两步验证。

## 3. 网页搜索（可选）

智能体用它查竞品、找论坛和公开讨论。不填也能用，系统自带免费搜索兜底，结果较少。在卡片里选对应服务，粘贴密钥。

### 3.1 Tavily（推荐，最简单）

1. 打开 tavily.com，注册登录（邮箱或 Google）。[截图：注册页]
2. 控制台首页直接显示 API Key（以 tvly- 开头），复制。[截图：控制台]
3. 粘贴到卡片，搜索服务选 Tavily。

免费额度：每月 1000 点，免费档不需要银行卡。超出：按量每点 0.008 美元，或月付套餐（Project 30 美元 / 月起）。一次基础搜索大约 1 点，高级搜索更多，以官网为准。

### 3.2 Perplexity

1. 打开 perplexity.ai，登录后进入设置里的 API 页面（perplexity.ai/settings/api）。
2. 添加付款方式并预充值，生成 API key 并复制。
3. 粘贴到卡片，搜索服务选 Perplexity。

价格：Sonar 每百万 token 输入输出各约 1 美元，另按请求收费，每千次 5～12 美元（取决于搜索深度）。无固定免费档。

### 3.3 Firecrawl

1. 打开 firecrawl.dev，注册登录。
2. Dashboard 里复制 API Key（以 fc- 开头）。
3. 粘贴到卡片，搜索服务选 Firecrawl。

免费额度：一次性 500 点（用完不再每月发放）。付费：Hobby 约 16 美元 / 月（3000 点，年付价），网页抓取 1 点 / 页，搜索约 2 点 / 10 条结果，以官网为准。

### 3.4 Google 自定义搜索（不建议新申请）

Google 官方页面写明：Custom Search JSON API 已不再接受新客户，现有客户须在 2027 年 1 月 1 日前迁移。所以新客户不要选这一项，改用 Tavily 即可。

## 4. YouTube Data API v3（可选）

对应卡片：密钥与连接 → YouTube，字段 API 密钥。与 Google 自定义搜索无关，不要混淆。

1. 打开 console.cloud.google.com，用 Google 账号登录，同意服务条款。[截图：控制台首页]
2. 顶部项目下拉框 → 新建项目，名称随意（例如 kelai-youtube）。[截图：新建项目]
3. 左侧 “API 和服务” → “库”，搜索 “YouTube Data API v3”，点 “启用”。[截图：启用 API]
4. 左侧 “API 和服务” → “凭据” → 创建凭据 → API 密钥，复制。[截图：创建密钥]
5. 建议点密钥旁的 “限制密钥”，API 限制里只勾选 YouTube Data API v3。
6. 粘贴到卡片。

配额与费用：每个项目每天默认 10000 配额点，免费，拿这个密钥不需要绑银行卡。不同操作消耗不同：搜索一次 100 点，读视频详情、读评论线程各约 1 点。所以搜索很费额度（一天约 100 次），读评论便宜。身份证件：不要。

多个密钥轮换：同一个项目里创建多个密钥，共享同一份配额，不能增加额度。想要更多额度有两条路：在 Google Cloud 控制台提交配额提升申请（正规做法，需说明用途，审核通过后提高）；或者用多个项目各自一份配额。按我对 YouTube 开发者政策的理解，用多个项目绕过配额可能被视为违规，有被封风险【待核实】，建议优先申请提升配额，多项目作为备选并自行评估。系统端支持填入多个密钥轮换，具体由开发线程实现。

## 5. 发件邮箱 SMTP（可选）

用于以后发送邮件通知（例如名单交付提醒）。不要用邮箱登录密码，必须用“授权码”或“应用专用密码”。

填写项：服务器、端口、账号、授权码。

### 5.1 QQ 邮箱

1. 网页版登录 mail.qq.com，进入 设置 → 账号。[截图：设置页]
2. 找到 “POP3/IMAP/SMTP 服务”，开启 SMTP 服务（需要用绑定手机发短信验证）。
3. 生成并复制 16 位授权码。
4. 填写：服务器 smtp.qq.com，端口 465（SSL），账号为完整 QQ 邮箱地址，密码填授权码。

### 5.2 163 邮箱

1. 登录 mail.163.com，进入 设置 → POP3/SMTP/IMAP。
2. 开启 SMTP 服务，按提示用手机验证，设置客户端授权密码并复制。
3. 填写：服务器 smtp.163.com，端口 465（SSL），账号为完整邮箱地址，密码填授权密码。

### 5.3 Gmail

1. 登录 Google 账号，进入 安全性，先开启“两步验证”。
2. 在两步验证页面里找到 “应用专用密码”，创建一个，复制 16 位密码。
3. 填写：服务器 smtp.gmail.com，端口 465（SSL），账号为完整 Gmail 地址，密码填应用专用密码。

三家都免费，不要证件。每天发信数量有上限，大批量群发不适合用个人邮箱。

## 6. 代理（可选）

只有在服务器所在网络访问不了某些服务（例如 Telegram、Google）时才需要。先不用，遇到“连不上”再考虑。

1. 向代理服务商购买，付款方式和是否要身份验证以服务商为准，多数不要证件。
2. 服务商会给你四样东西：地址、端口、用户名、密码。
3. 按下面格式拼成一行，粘贴到代理输入框：
   - HTTP 代理：`http://用户名:密码@地址:端口`，例如 `http://user1:pass1@203.0.113.10:8080`
   - SOCKS5 代理：`socks5://用户名:密码@地址:端口`，例如 `socks5://user1:pass1@203.0.113.10:1080`
   - 没有用户名密码的：`http://地址:端口`
4. 密码里有 @ : / 等特殊字符时，需要先转义（例如 @ 写成 %40）；不确定就让服务商换一个纯字母数字的密码。
5. 点“测试连接”确认通过。

## 7. 国内客户怎么办（备选方案）

以上主流程默认你能直接注册和付款海外服务。如果在国内遇到下面的障碍，用这些办法：

- 大模型：优先选国内平台。DeepSeek、通义千问（阿里云百炼）、Kimi、智谱、MiniMax 都可以用国内手机号注册，按提示完成实名认证（通常需要身份证），支持支付宝或微信充值，不需要海外银行卡。
- OpenAI、Anthropic 在国内无法直接注册和付款：可以改用国内平台，或使用合规的 API 转售商（价格和稳定性各异，选择时注意对方是否会保留你的对话内容），或让海外同事 / 合作方代为注册并充值。转售商给的密钥和服务地址，选“自定义”服务商并填入服务地址即可。
- Google 相关（Gemini、YouTube）：国内网络无法直接访问 Google 注册页，需要先解决网络（见第 6 节代理）。Google 账号注册可能要求海外手机号验证；做不到时 YouTube 可先不配，不影响主流程。
- Telegram：国内网络通常连不上，服务器需要部署在海外或配置代理。
- 网页搜索：Tavily、Perplexity 需要海外网络和海外付款方式；暂时不配也可以，系统有免费兜底。
- 邮箱：QQ、163 邮箱国内直接可用，是国内客户最方便的选择。

## 8. 申请完成后的自检清单

- 大模型卡片显示“已连接”（必填）。
- Telegram 接口凭据卡片显示“已连接”（必填），然后到“Telegram 账号”页登录。
- 其他可选卡片按需配置，显示“未配置”不影响使用。
- 任何一张显示“无效”，先看提示里的原因，常见是复制不完整、额度为 0 或网络问题。
